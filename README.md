# Devixo-AI-ML-Internship-Task-01

## Task 01: Python Programming, Data Analysis & Visualization

### Project Overview
This project focuses on analyzing the **Students Performance in Exams** dataset using Python. The main objective is to perform data cleaning, preprocessing, Exploratory Data Analysis (EDA), statistical analysis, and data visualization to identify meaningful patterns and insights related to students' academic performance.

### Dataset Information
- **Dataset Name:** Students Performance in Exams
- **Dataset Source:** [Kaggle – Students Performance in Exams](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)
- **Number of Rows:** 1,007
- **Number of Columns:** 8
- **Categorical Features:** 5
- **Numerical Features:** 3

### Dataset Features
The dataset contains the following columns:

**Categorical Features:**
- Gender
- Race_Ethnicity
- Parental_Education
- Lunch_Type
- Test_Preparation

**Numerical Features:**
- Math_Score
- Reading_Score
- Writing_Score

### Project Workflow

1. **Data Loading:** Imported the dataset using Pandas.
2. **Data Inspection:** Examined rows, columns, data types, and missing values.
3. **Data Cleaning:** Identified and handled missing values, duplicate records, incorrect data types, and invalid values.
4. **Data Preprocessing:** Standardized categorical values and prepared the dataset for analysis.
5. **Exploratory Data Analysis (EDA):** Explored patterns and distributions in the dataset.
6. **Statistical Analysis:** Calculated mean, median, mode, minimum, maximum, variance, standard deviation, and correlation.
7. **Data Visualization:** Created different charts using Matplotlib and Seaborn.
8. **Insights and Findings:** Identified important trends and relationships in students' academic performance.

### Key Findings

- Reading has the highest average score among the three subjects.
- Reading and Writing scores have a strong positive correlation.
- Students who completed test preparation generally achieved higher average scores.
- Female students performed better in Reading and Writing on average, while male students performed better in Mathematics.
- Mathematics scores showed slightly greater variation than Reading and Writing scores.
